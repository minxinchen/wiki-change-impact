# 一次看懂：Agent 如何使用 Wiki

這是一組**合成教學資料**，可直接在 GitHub 點開閱讀，沒有私人對話。

## 任務與讀取順序

使用者問：「可以用第三方工具處理這份文件嗎？」

1. Agent 先讀 [索引](vault/INDEX.md)，找到「選用第三方工具處理資料、安裝工具或串接外部服務」。
2. 讀 [工具選用規則](vault/wiki/tool-selection.md)，知道要先審查，也知道不是全面禁止。
3. 若不確定規則原意，回查 [原始討論](vault/raw/tool-policy-v1.md)。
4. 預期回覆：「需要先確認工具來源、權限與用途；請提供工具資訊，再判斷能否使用。」

以上是設計的讀取路徑及預期回覆，不是本次模型執行結果。你可以把這個任務與索引交給有讀檔能力的 agent，再觀察它實際讀了哪些文件。

## 原始規則補充後，哪裡需要跟著檢查？

[新版原始討論](vault/raw/tool-policy-v2.md)增加「內部文件外傳需要授權」。

執行 repo 根目錄的 `agent-wiki-demo.py`，會在隔離複本中將規則頁來源切換到新版，保留舊紀錄與尚未修訂的規則正文，再呼叫既有變更檢查器。

預期產生兩項待核對項目：

| 頁面 | 為什麼列入 | 人或 reviewer 要檢查什麼 |
|---|---|---|
| `wiki/tool-selection.md` | 它引用的來源版本改了 | 是否補上文件外傳的授權條件 |
| `INDEX.md` | 它依據上面的規則頁 | 索引摘要與適用任務是否也需要調整 |

程式能列出影響路徑；表格最後一欄是人工解讀，程式不理解或自動補寫規則。索引列入待核對也不表示一定要改。
