# 可檢查的去識別節錄

Author: Nio (Master) · Selection: Codex · 2026-10-11

以下是私人材料的短節錄，機型代碼以「機型A／B」替代，床寬數值省略。省略與代碼替換明示於各項，不是新的合成案例；完整版與原始路徑映射留在本機。這些片段支持列出的窄主張，不足以讓外部讀者重驗整個私人 corpus。

## E1 — 使用者校正紀錄

2026-04-14 保存材料明示「使用者原話（重組整理）」，不是逐字錄音：

> 「可擴充」是**錯誤框架**—— auxiliary guideway 是 機型B 結構**必備**，不是 optional 也不是升級

僅將機型代碼替換為「機型B」。支持：校正紀錄明確區分必要結構與選配。不能推出：第三方工程認證，或校正後所有回答皆正確。

## E2 — 舊卡與現行頁的衝突

## E3 — 修補入口的意義

實驗 C 的修補規則（本輪新增，非歷史原文）：

同時為兩個已含校正內容的頁面補上 correction source。完整差異只在本機。實測 B/C 都未讀這三個修補檔，因此這次不能判定修補規則有效或無效。

## E4 — 有引用仍可能錯譯

現行頁原文短節錄：

> **Dual Carriage（雙床鞍）：**

A/B/C 真實模型輸出共同片段：

> 雙刀塔（dual carriage）

這是術語錯譯；定位大方向吻合不能抵銷名詞錯誤。回答原稿保留，未由作者改成正確答案後再評分。

## E5 — 無依據的全面判斷

實際工具 trace：讀了校正原文和現行機型頁，未讀舊卡，也未讀修補入口。此說法超出它實際檢索的範圍；E2 足以反駁「整個可見材料無衝突」。
