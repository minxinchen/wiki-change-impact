# 本案例可以如何驗證

[回首頁](../../README.md)

Author: Nio (Master) · Evidence review and editing: Codex · 2026-10-14

狀態：概念案例的驗證問題，尚未執行；本輪範圍是清楚呈現既有架構，不新增實驗。

| 問題 | 應檢查的證據 |
|---|---|
| Agent 是否真的按需載入？ | 實際讀取的節點與回傳正文，不接受只看過檔名的自評 |
| 是否保留規則原意？ | 回答同時包含原因與適用條件，沒有把審查要求改成一律禁止 |
| 是否可以追溯？ | 節點的來源能找到支撐段落；缺失應明示 |
| 校正是否整合？ | 節點與索引同步，舊規則的取代或衝突關係明確 |
| 新 session 是否仍可使用？ | 不靠前輪對話提示的新任務讀取與判斷紀錄 |

若未來執行，需固定資料與任務，分開記錄文件結構檢查、模型讀取、答案判斷及限制。其他領域的既有實驗結果不能移作本案例的結果。
